# Project: Immersive Experience Builder

## What It Is

A framework and visual tool for creating interactive, sensor-driven spatial experiences. It's essentially a component library for immersive installations — over 100 components covering sensors, actuators, lighting, sound, and interaction patterns. It helps designers and technologists create experiences that respond to movement, sound, and environmental conditions.

## My Role

Framework Design — I designed the entire system architecture, component taxonomy, and visual tool.

## When

2024

## Why I Built It

Immersive experience design has no standardized toolkit. Every installation starts from scratch. I wanted to create a reusable framework that captures best practices and common patterns, making it faster to go from concept to working prototype.

## Technologies Used

Component-based architecture, sensor integration patterns, spatial interaction design

## Why It Matters

This is the project I'm most personally proud of. It represents my unique intersection — hardware knowledge (sensors, actuators), software skills (component architecture), and design thinking (user interaction patterns). It also directly built on my Apple Vision Pro experience with spatial computing.
