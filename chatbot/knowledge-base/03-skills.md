# Technical Skills

My primary development focus. I build with React, TypeScript, and modern frontend tooling (Vite, Next.js). Beyond frontend, I'm comfortable with Node.js backends, serverless functions (Supabase Edge Functions, Vercel), REST APIs, and database design (PostgreSQL, Supabase). I use Python for data processing, scripting, and ML-adjacent work.
